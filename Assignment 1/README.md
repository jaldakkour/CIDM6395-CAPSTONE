  In terms of integration, data analytics has a unique relationship and functionality with each of the other subject categories in the program. Data analytics is perhaps most reliant on data management, which has a focus on ensuring data is accurate, reliable, and ready to be used when called upon. Data analytics would be impossible to do without data management being performed, as data management is what collects, organizes, stores, and secures the data that data analytics are performed on. The Extract, Transform, and Load (ETL) process is a data management process that prepares data to be used in programs that perform analytical functions such as Tableau and R. This process shows one way in which data management is a necessary first step for analytics to prevail. It is in this way that data analytics and management are integratable with each other. 

	Data analytics and software development are two topics that are also highly integrated in this master's program. Data analytics should be used throughout the software development lifecycle (SDLC). In the planning and requirements phase, it can inform software developers of business needs, which can help to identify features that will be more valuable to include over others. In the design phase, data analytics can assist with identifying cycle times, bottleneck areas, as well as areas that can be made more efficient and streamlined. In the testing phase, analytics can be used to filter through logs and error reports to help identify causes of problems. In the deployment and maintenance phase, analytics can be used to provide continuous feedback on how the software is performing. It can also be used to track system usage. A great example of data analytics’ integration with software development can be seen in many shopping apps, one such including Amazon. Amazon’s application has a continuous learning feature in which it collects and analyses data about items that its users look at and purchase to present its users with similar options that they may also enjoy. It also uses analytics to identify shopping patterns within users and uses prediction models to determine what items to advertise and when.  

 

	Data analytics is extremely integrated with the networking and cybersecurity section as well, as these sections represent a flow of information from one section to the next. The network in this relationship provides the data for analytics to be performed on. Analytics can be done to track which devices are communicating with each other within a network, the data packets being sent and received, as well as system logs. Analytics being performed on these items to establish network communications patterns and identify items fall outside of those norms, or to use predictive analysis to anticipate future cyber-attacks based on historical ones. These analytics that are performed then feed into the cybersecurity aspect of this flow. The analytics are used by cybersecurity specialists to develop standards and policies and to perform risk management by prioritizing the most threatening vulnerabilities.
