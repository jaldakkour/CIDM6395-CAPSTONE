In terms of integration, data management is a foundational base upon which each of the other topics in the MSCISBA degree program are built. It is the fundamental first step that all data driven activities must perform. Data management prepares data for analysis in business and cyber security activities, as well as for use in software development, making it highly integrated with data analytics. Data management has a focus on collecting, storing, organizing, and maintaining quality data in preparation for analysis. Without proper data management, there would not be data that is easily accessible for data analysis to be performed on, nor would there be a guarantee that the data being analysed would be accurate. The Extract, Transform, and Load (ETL) process is a data management that extracts data from operational systems such as APIs or databases, cleans the data by fixing missing values, converting the data to a standard format, and loads the cleaned data into a data warehouse for storage. This process prepares the data so it can be used in data analytics programs such as Tableau, RapidMiner, R Studio, etc. This shows how the data management and data analytics processes are two integral, sequential steps in a data-driven process.  

Data management and software development are also highly integrated sections in the MSCISBA program which is shown throughout the entire software development lifecycle (SDLC). Data management is used in the data modelling process to identify all data entities, attributes, and relationships in a dataset so that the database schema can be established. Data management is also necessary to determine what kind of database technology will be best to store the data in based on the data type, amount, and other things determined to be necessary. As data management helps to establish necessary aspects of software development, software development also assists in data management. Software developers build the extract, transform, and load process that is vital to good data management. They also use application programming interfaces (APIs) to create interfaces for applications to communicate with as well as read and write data that remains within constant access. It is in these ways that data management and software development have a symbiotic nature in their relationship.  

Data management and networking and cybersecurity are also highly integrated sections of the MSCISBA program which are highly reliant upon each other. For data management to occur, there must be a secure and trusted network established where the data can be stored for the rest of the data management process to occur. In return, data management helps to establish what network and security measures must be established based upon the types of data that data management states. Data governance and data classification are data management concepts which sets the rules on how data needs to be handled, as well as the level of security necessary for that data storage and transmission.  Networking and cybersecurity, in return, establishes ways to secure the data against attacks, but also against internal unauthorized users which could affect the data’s integrity. These are only a few examples that show how the data management and networking and cybersecurity topics are integrated with each other.
